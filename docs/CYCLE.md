# Development cycle

1. Unzip / clone this baseline locally.
2. Create `.env` and run `pnpm install`.
3. Work locally with Codex/IDE and test on real devices.
4. Commit meaningful changes to a branch.
5. Push to GitHub.
6. Ask ChatGPT to inspect the current repository and diff.
7. Apply review/fixes through branches or local work.
8. Repeat until real call, AI latency, mobile UX and deployment checks pass.

Do not treat a visually complete screen as evidence that the call pipeline works. Use real two-device tests.
